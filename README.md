# Spanish Immersion for WCSD

Parent-led community website supporting exploration of Spanish-English immersion education in the Walnut Creek School District.

## Site
This repository contains a simple static site designed for GitHub Pages.

## Main files
- `index.html` — page content
- `styles.css` — site styling
- `logo.svg` — site logo/favicon

## Publishing
In GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.

## Custom domain
The intended primary domain is `BringSpanishEdtoWalnutCreek.org`. The `.com` domain can redirect to the `.org`.

## Maintenance
Content should remain parent-led and clearly distinguish this site from official Walnut Creek School District communications.
